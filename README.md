# 🍽️ Restaurant Management — Python OOP

A simple **restaurant management system built with Python**, designed to practice **Object-Oriented Programming (OOP)** concepts through a command-line application.

## 📖 About the Project

This project is a terminal-based application that allows users to manage a list of restaurants.

The system uses a `Restaurant` class to represent each restaurant and provides options to add, remove, and list registered restaurants.

## ✨ Features

* Add a restaurant
* Remove a restaurant by ID
* List registered restaurants
* Display restaurant status
* Interactive command-line menu
* Basic input validation

Each restaurant receives an automatically generated ID and is stored in a class-level list.

## 🛠️ Technologies

* Python 3
* Object-Oriented Programming
* Command Line Interface (CLI)

## 📚 OOP Concepts Practiced

The project uses several Python OOP concepts, including:

* Classes and objects
* Constructors (`__init__`)
* Class attributes
* Instance attributes
* `@staticmethod`
* `@classmethod`
* Properties with `@property`
* Special methods such as `__repr__`

## 📂 Project Structure

```text
Restaurant-Management-OO-Python/
│
└── OO Python/
    ├── app.py
    └── restaurant.py
```

### `app.py`

Entry point of the application. It imports the `Restaurant` class and starts the main menu.

### `restaurant.py`

Contains the `Restaurant` class and the application's management logic, including restaurant registration, removal, listing, status handling, and the interactive menu.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/EduPanage/Restaurant-Management-OO-Python.git
```

### 2. Navigate to the project directory

```bash
cd Restaurant-Management-OO-Python/"OO Python"
```

### 3. Run the application

```bash
python app.py
```
